# عالم المغامرات الذكي (Kids Adventure App)

تطبيق تعليمي تفاعلي آمن للأطفال في سن 4-7 سنوات، يجمع بين القصص المصورة والألغاز التفاعلية لتنمية المهارات اللغوية والمنطقية والحركية.

## المميزات الرئيسية

- 🎮 **قصص تفاعلية** - قراءة صوتية مع إبراز الكلمات وعناصر قابلة للضغط
- 🧩 **ألغاز سحب وإفلات** - مطابقة الأشكال، الحروف، الأرقام، والتصنيف
- ⭐ **نظام مكافآت** - نجوم، مستويات متسلسلة، وألبوم ملصقات
- 👨‍👩‍👧‍👦 **بوابة أهل محمية** - تحدي رياضي للوصول للإعدادات
- ⏰ **إدارة وقت الشاشة** - حدود يومية (15/30/45 دقيقة)
- 🌐 **يعمل بدون إنترنت** - جميع المحتوى مدمج في التطبيق
- 🔒 **آمن للأطفال** - لا إعلانات، لا مشتريات، لا جمع بيانات

## المتطلبات التقنية

- Flutter 3.19+
- Dart 3.3+
- Android 5.0+ (API 21)
- iOS 12.0+

## قاعدة البيانات (Offline-First)

يستخدم التطبيق **Drift** مع **SQLite** للتخزين المحلي:

- `profiles` - بيانات الطفل (الاسم، إجمالي النجوم)
- `settings` - الإعدادات (وقت الشاشة، الصوت، بوابة الأهل)
- `level_progress` - تقدم المستويات (النجوم، الإكمال، المحاولات)
- `sticker_collection` - الملصقات المفتوحة

## محرك السحب والإفلات

ميزات محرك السحب والإفلات المخصص:

- ✅ **حارس اللمسة الواحدة** - يتجاهل الأصابع الإضافية أثناء السحب
- ✅ **الالتقاط التلقائي** - انيميشن نابضي عند الوصول للهدف الصحيح
- ✅ **العودة السلسة** - انيميشن مرن عند الإفلات في مكان خاطئ
- ✅ **ردود فعل لمسية وصوتية** - تغذية راجعة فورية
- ✅ **أداء عالي** - استجابة أقل من 100ms

## إدارة الصوت

- **ثلاثة مشغلات منفصلة** - مؤثرات، موسيقى، سرد صوتي
- **منع التداخل** - إيقاف الصوت السابق فوراً عند تشغيل جديد
- **تحميل مسبق** - جميع الأصوات محملة في الذاكرة للتشغيل الفوري
- **جلسة صوتية محسنة** - تصنيف `ambient` للسماح بالخلط مع تطبيقات أخرى

## بوابة الأهل

- تحدي رياضي ديناميكي: `a + b = ?` حيث a,b ∈ [1,9]
- 3 محاولات كحد أقصى قبل القفل المؤقت (30 ثانية)
- التخزين الآمن عبر `flutter_secure_storage`
- إدارة وقت الشاشة اليومية مع إعادة تعيين تلقائية

## الترجمة والتعريب

- **العربية (افتراضي)** - دعم RTL كامل
- **الإنجليزية** - ترجمة كاملة
- ملفات الترجمة في `assets/i18n/{ar,en}.json`
- استخدام `easy_localization` للتبديل الفوري
